# Fake News Detection

Machine learning project that classifies news headlines as Real or Fake. Text is converted to TF-IDF features and classified with a Multinomial Naive Bayes model, evaluated with accuracy, a confusion matrix and a classification report. Built on a small sample dataset for demonstration.

**Tools:** Python, Pandas, scikit-learn

**Run:** `pip install pandas scikit-learn` then `python fake_news_detection.py`
